# SD_* URP materials (staged, not in Assets/)

- `Materials/SD_Red|SD_Blue|SD_White|SD_Chrome.mat`: URP Lit, metallic workflow, generated by `Editor/SDMaterials.cs` from the Blender palette.
- Blender's colours are linear; the script writes them as `Color.gamma`, so they look the same in Linear and Gamma projects.
- To use: copy `Materials/` into the project (e.g. `Assets/BikiniWipeout/Materials/SD/`), copy an FBX next to it, then either run `SDMaterials.Remap("<fbx path>")`
  (remaps by material name) or set the remaps in the FBX Import Settings > Materials > Remap.
- The .mat files carry no .meta; Unity creates GUIDs on first import. Do not copy them over existing project materials.
